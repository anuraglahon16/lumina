### On the socket counts above

Decoded, the listening sockets are:

  gateway  8080  + 127.0.0.11:<ephemeral>
  agent    8787  + 127.0.0.11:<ephemeral>
  worker          127.0.0.11:<ephemeral>   <- only this

127.0.0.11 is Docker's embedded DNS resolver, which exists in every container on
a user-defined network. The worker has no application listener of its own: its
only socket is the one Docker gives it for name resolution. That is the accurate
form of "the worker has no HTTP listener" — the count is not zero, and saying so
would be wrong.
